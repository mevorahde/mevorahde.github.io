# Security and privacy

This portfolio is a static website. It has no backend, authentication, form,
database, runtime configuration, cookies, analytics, or executable client-side
code.

## Reporting a problem

Use the repository's private vulnerability-reporting feature for a security or
privacy concern once the repository is public. For non-sensitive corrections,
use a normal GitHub issue after publication. Do not include credentials,
private records, or other sensitive information in a public issue.

## Scope

Linked projects have their own security policies and limitations. A link or
summary on this site is not a security certification, warranty, or expansion of
another project's support policy.
